# Prompt per la fase di scrittura

Apri una nuova conversazione in un sistema non Anthropic.

```text
Scrivi un testo nuovo partendo dalla scheda qui sotto.

Regole:
- Lavora sulle idee e sui vincoli, non su frasi precedenti.
- Conserva ogni valore protetto in modo esatto.
- Scegli una struttura nuova e utile al lettore.
- Usa verbi concreti e una lunghezza naturale delle frasi.
- Non aggiungere fatti.
- Non citare questo metodo, filigrane o detector.
- Restituisci soltanto il testo.

Scheda di ricostruzione:
INCOLLA QUI IL JSON CONTROLLATO
```

Se la prima versione conserva troppo la struttura originale, chiedine una seconda con un ordine diverso.

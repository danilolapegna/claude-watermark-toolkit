# Metodo 8: catena di riscritture indipendenti

Usala soltanto quando esiste già una scheda a camera stagna controllata e una singola nuova stesura conserva ancora troppa struttura della fonte.

## La catena sbagliata

Fonte → Bozza 1 → Bozza 2 → Bozza 3.

Ogni passaggio vede le parole del precedente. Gli errori di significato e la prosa generica si accumulano come nel telefono senza fili.

## La catena più prudente

Scheda controllata → Bozza indipendente A.

La stessa scheda controllata → Bozza indipendente B con un ordine diverso delle idee.

La stessa scheda controllata → Bozza indipendente C con un pubblico o un formato diverso.

Confronta tutte e tre con i fatti della fonte, poi scegli o combina a livello di idee. Non incollare insieme frasi soltanto perché hanno poca somiglianza.

## Perché resta sperimentale

Chainwash riporta una rimozione più forte dopo riscritture indipendenti ripetute in configurazioni di watermark per diffusion language model. È un'evidenza utile per il pattern, non un risultato sul detector privato di Claude.

## Quando fermarsi

Fermati quando i fatti slittano, le precisazioni spariscono oppure tutte le bozze iniziano a suonare generiche. Correggi la scheda o usa un editor umano. Più passaggi non significano automaticamente più indipendenza.
